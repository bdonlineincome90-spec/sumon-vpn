# বাড়ির রাউটার রিলে সার্ভার

বাড়ির ফোন (হোম অ্যাপ) আর দূর থেকে কন্ট্রোল করা প্যানেলের মাঝখানের সেতু।
Python ছাড়া আর কিছু লাগে না — কোনো লাইব্রেরি ইনস্টল করতে হয় না।

## VPS-এ চালানো (পরে, VPS কেনার পর)

```bash
python3 relay.py          # পোর্ট 8080-এ চলবে
# বা অন্য পোর্টে:
python3 relay.py 9000
```

সার্ভার চালু থাকলে অ্যাপের সার্ভার ঠিকানায় বসাতে হবে:
`http://VPS-এর-IP:8080` (যেমন `http://1.2.3.4:8080`)

সার্ভার সবসময় চালু রাখতে (VPS রিস্টার্ট হলেও নিজে উঠবে):

```bash
# systemd সার্ভিস (উবুন্টু/ডেবিয়ান VPS-এ):
sudo tee /etc/systemd/system/home-relay.service > /dev/null <<'EOF'
[Unit]
Description=Home router relay
After=network.target

[Service]
ExecStart=/usr/bin/python3 /opt/home-relay/relay.py 8080
Restart=always
User=www-data

[Install]
WantedBy=multi-user.target
EOF
sudo systemctl enable --now home-relay
```

ফায়ারওয়ালে 8080 পোর্ট খুলে দিতে হবে (VPS-এর ফায়ারওয়াল / `ufw allow 8080/tcp`)।

## কী করে

1. বাড়ির ফোনে অ্যাপ খুলে **কোড বানান** চাপলে ৬ সংখ্যার কোড আসে — সেটা এই
   সার্ভারে ৩০ মিনিটের জন্য নিবন্ধিত হয়।
2. সুমন প্যানেলে/ব্রাউজারে সেই কোড দিয়ে রাউটারের পেজ খুললে অনুরোধটা
   এই সার্ভারে এসে জমা হয়; বাড়ির ফোন সেটা নিয়ে রাউটার (192.168.0.1)
   থেকে উত্তর এনে ফেরত দেয়।
3. ৩০ মিনিট পর কোড নিজে মরে যায়; অ্যাপ থেকে **বন্ধ করুন** চাপলেও
   সাথে সাথে বন্ধ হয়।

## নিরাপত্তা

- কোড ছাড়া কেউ কিছু পায় না; কোড ৬ সংখ্যার, ৩০ মিনিটের।
- সার্ভার অনুরোধ/উত্তরের ভেতরের ডেটা (body) কখনো লগ করে না, জমিয়েও
  রাখে না — শুধু একবার ফরওয়ার্ড করে ছেড়ে দেয়। রাউটারের পাসওয়ার্ড
  সার্ভারের কাছে শুধুই ফরওয়ার্ড করা বাইট।
- সেশন শেষ হলে কোড আর কিউ মুছে যায়।
- ভুল কোডের তালা: একই IP থেকে ৫ মিনিটে ৫ বার ভুল কোড দিলে সেই IP
  ১৫ মিনিট বন্ধ থাকে। সঠিক কোড দিলে ভুলের হিসাব মুছে যায়।
